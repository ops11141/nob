# قاموس البيانات

كل عنصر يحتفظ بنوعه وطبقة الرسم وإحداثياته الأصلية.

الأنواع الرئيسية:
LINE, LWPOLYLINE, POLYLINE2D, POLYLINE3D, ARC, CIRCLE, ELLIPSE, SPLINE, HATCH, INSERT, TEXT, MTEXT, ATTRIB, ATTDEF, DIMENSION, LEADER.

لا يتم حذف أي عنصر. العناصر غير المصنفة تحفظ للمراجعة.

إحداثيات CAD الأصلية هي المرجع الأساسي. أي تحويل إلى Latitude/Longitude يحفظ في حقل منفصل.
