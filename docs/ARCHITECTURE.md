# NOB Architecture

GEO.dwg هو مصدر غير قابل للتعديل.

المسار:
DWG → LibreDWG → raw objects → normalized entities → classification → relationships → GeoJSON → search/dashboard/map.

المجالات:
entities, layers, blocks, texts, geometry, equipment, feeders, cables, joints, geojson, qa.

أي عنصر غير مصنف يبقى في raw dataset ولا يتم حذفه.
