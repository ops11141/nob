# NOB — GEO.dwg Data Platform

مشروع مستقل جديد لتحويل ملف GEO.dwg إلى قاعدة بيانات هندسية قابلة للبحث والتحليل والخريطة.

الهدف ليس تصفح الرسم كـ CAD Reader فقط. سيتم استخراج:
- جميع العناصر الهندسية.
- الخطوط والـPolyline والأقواس والدوائر والـSpline.
- الطبقات Layers.
- النصوص وMTEXT.
- Blocks وINSERT.
- المعدات والرموز الهندسية.
- المغذيات ومساراتها.
- الكابلات والوصلات.
- الإحداثيات الهندسية.
- العلاقات بين العناصر.
- ملفات GeoJSON.
- فهارس البحث والإحصائيات.

GEO.dwg هو المصدر ولا يتم تعديله. كل البيانات الناتجة مشتقة منه.

الحالة: تم إنشاء المستودع من الصفر. حجم المصدر الحالي 29,310,275 بايت.

الأرقام النهائية للعناصر الهندسية يجب أن تأتي من كائنات DWG الفعلية، وليس من عد النصوص فقط.
